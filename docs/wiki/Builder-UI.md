# Builder UI

The builder UI is served by the amSetup executable on localhost.

Main sections:

- Product details
- Payload and package settings
- Branding
- Window Designer
- Shortcut
- Install Folders
- Registry
- Dependency Analysis
- Prerequisites
- Theme
- Advanced manifest JSON

The Window Designer controls setup title, subtitle, intro text, footer text,
style, dimensions, and sidebar preview.

The package settings expose every owned compression mode: Brotli, zlib, LZ4HC,
LZMA, LZMA2, aPLib, DEFLATE, GZip, XZ, and store.

Use Exit Builder when you are done. It shuts down the local amSetup host
process instead of only closing the browser tab.
